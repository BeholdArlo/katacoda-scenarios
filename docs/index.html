🎵 Spotify Setup — 30 Seconds

Unlock Spotify Search

Spotify requires a free API key. You only do this once. No payment, no subscription — just a free developer account.

  • 1 Visit developer.spotify.com/dashboard and log in with your regular Spotify account.
  • 2 Click "Create app". Name it anything (e.g. "My Mixer"). Under Redirect URIs, type exactly: audiomixer://spotify-callback
  • 3 Click Save. Then click Settings and copy your Client ID (looks like: abc123def456...).
  • 4 Open AudioMixer → tap the ⚙️ gear icon → paste your Client ID → done! Spotify search is unlocked instantly.

❓ Common Questions

FAQ


Is this free?

Yes. AudioMixer is free and open source. SideStore is free. The Spotify API key is free.

Do I need a Mac?

No. The IPA is pre-built via GitHub Actions. SideStore re-signs it using your free Apple ID entirely on-device.

Will SideStore expire?

Free Apple IDs need app refresh every 7 days. SideStore does this automatically in the background over Wi-Fi — no action needed from you.

Can I hear YouTube and Spotify at the same time?

Yes — that's the whole point. AudioMixer uses AVAudioSession.mixWithOthers so both sources play simultaneously without ducking each other.
